Assistance

Courtside : Tennis Manager

Nous contacter

Une question, un bug, une idée ? Écrivez-nous sur github.com/OuTaG/tennis-manager/issues. Indiquez votre modèle d'iPhone, la version d'iOS et, si possible, une capture d'écran.

J'ai changé de téléphone : comment récupérer mes achats ?

Dans le jeu, ouvrez la Boutique puis touchez « Restaurer les achats ». Utilisez le même identifiant Apple que lors de l'achat.

Mes carrières ont-elles disparu ?

Les carrières sont enregistrées uniquement sur votre appareil. Elles sont supprimées si vous supprimez l'application. Elles ne se transfèrent pas d'un appareil à l'autre.

Remboursement

Les achats sont gérés par Apple. Pour une demande de remboursement : reportaproblem.apple.com.

Confidentialité

Courtside ne collecte aucune donnée personnelle. Voir la politique de confidentialité.
